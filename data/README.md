# Data policy

The files in sample_resumes/ are fictional demonstration profiles created for this project. They do not represent real people.

Do not commit real resumes or candidate personal data. Uploaded files are processed in memory by the Streamlit app and the project code does not persist them. Check the hosting provider's own logging and retention policies before deploying or processing any personal information.

No external real-resume dataset is redistributed or required. The ranking evaluation uses clearly disclosed synthetic relevance judgements in src/evaluate.py.
